TrunkDeck's own code (the window, the P25 engine, the SDR drivers) is licensed under the GNU GPL v3.0 or later. It was written from the published
TIA-102 (APCO Project 25) standards:
  TIA-102.BAAA-A  FDMA Common Air Interface (NID BCH code, trellis code and interleaver, Golay / Hamming / Reed-Solomon codes)
  TIA-102.BAAC-A  CAI Reserved Values (Data Unit IDs and NID parity bits)
  TIA-102.AABC    Trunking control channel messages
  TIA-102.BBAB / TIA-102.BBAC / TIA-102.BBAC-1  Phase 2 TDMA physical and MAC layers (DUID and I-ISCH codes, RS(63,35)
                  mother code, CRC-12, scrambling sequence, MAC messages)
The error-correction and coding tables are built from these definitions when the program starts
(source/src/p25monitor/p25/CodeTables.java). Each table names the standard section it comes from, and
source/test/p25monitor/p25/CodeTablesTests.java checks them against the values printed in the standards.

The NXDN decoder (source/src/p25monitor/nxdn) is TrunkDeck's own code, written for this program. The NXDN Forum
specifications (NXDN TS 1-A and related parts) were not used directly. The protocol facts it relies on were read from
the open-source sdrtrunk decoder (GPL-3.0, https://github.com/DSheirer/sdrtrunk): the frame sync word, LICH layout,
PN9 scrambler, interleaver sizes, convolutional code polynomials and puncturing patterns, CRC polynomials, and layer 3
message field positions. No sdrtrunk source code, class structure or comments were copied. Facts such as polynomials
and bit positions are part of the air interface and are not copyrightable expression.

The analog FM receiver (source/src/p25monitor/analog) is TrunkDeck's own code. Its CTCSS tone list is the standard
EIA/TIA set. The general approach (Goertzel tone measurement on 8 kHz audio) was compared with sdrtrunk's
NBFM decoder; no code was copied.

The Motorola Type II (SmartNet / SmartZone) decoder (source/src/p25monitor/motorola) is TrunkDeck's own code, written
for this program. Motorola has not published the protocol. The facts it relies on were read from two open-source
programs: gr-smartnet by Nick Foster (GPL, https://github.com/bistromath/gr-smartnet) for the 3600 bit/s frame (sync
word, 19 x 4 interleave, parity code, check value and the field inversion constants), and trunk-recorder (GPL-3.0,
https://github.com/TrunkRecorder/trunk-recorder) for the message meanings (grant and update words, talkgroup status
bits, control channel and system ID words) and the 800 / 900 MHz and VHF/UHF band plans. No source code, class
structure or comments were copied from either. Like the NXDN facts above, these are properties of the air interface.

The full list, with licence texts, is in licenses/THIRD-PARTY.txt. In short:

* Bundled, unmodified, as separate libraries:
  - FlatLaf (Apache-2.0).

  - libairspy / airspyone_host (BSD-3-Clause): the USB protocol reference for TrunkDeck's own Airspy driver. Its
