TrunkDeck's own code (the window, the P25 engine, the SDR drivers) is licensed under the GNU GPL v3.0 or later. It was written from the published
TIA-102 (APCO Project 25) standards:
  TIA-102.BAAA-A  FDMA Common Air Interface (NID BCH code, trellis code and interleaver, Golay / Hamming / Reed-Solomon codes)
  TIA-102.BAAC-A  CAI Reserved Values (Data Unit IDs and NID parity bits)
  TIA-102.AABC    Trunking control channel messages
  TIA-102.BBAB / TIA-102.BBAC / TIA-102.BBAC-1  Phase 2 TDMA physical and MAC layers (DUID and I-ISCH codes, RS(63,35)
                  mother code, CRC-12, scrambling sequence, MAC messages)
The error-correction and coding tables are built from these definitions when the program starts
(source/src/p25monitor/p25/CodeTables.java). Each table names the standard section it comes from, and
source/test/p25monitor/p25/CodeTablesTests.java checks them against the values printed in the standards.

The analog FM receiver (source/src/p25monitor/analog) is TrunkDeck's own code. Its CTCSS tone list is the standard
EIA/TIA set. The general approach (Goertzel tone measurement on 8 kHz audio) was compared with sdrtrunk's
NBFM decoder; no code was copied.

The Motorola Type II (SmartNet / SmartZone) decoder (source/src/p25monitor/motorola) is TrunkDeck's own code, written
for this program. Motorola has not published the protocol. The facts it relies on were read from two open-source
programs: gr-smartnet by Nick Foster (GPL, https://github.com/bistromath/gr-smartnet) for the 3600 bit/s frame (sync
word, 19 x 4 interleave, parity code, check value and the field inversion constants), and trunk-recorder (GPL-3.0,
https://github.com/TrunkRecorder/trunk-recorder) for the message meanings (grant and update words, talkgroup status
bits, control channel and system ID words) and the 800 / 900 MHz and VHF/UHF band plans. No source code, class
structure or comments were copied from either. Facts such as these are properties of the air interface.

The EDACS control channel message decoding (source/src/p25monitor/edacs/EdacsSite.java) is a Java translation of
the EDACS message parsing in DSD-FME (ISC licence, Copyright (C) 2010 DSD Author, https://github.com/lwvmobile/dsd-fme),
written by lwvmobile (EDACS-FM) and ilyacodes with portions from ledacs by SP5WWP (The Unlicense). The licence text is
in licenses/DSD-FME-ISC.txt and at the top of that file. DSD-FME's BCH code (edacs-bch3.c) is not used.

The rest of the EDACS and ProVoice decoder (the 9600 bit/s receiver, frame voting, BCH(40,28) correction, and the
ProVoice voice channel) is TrunkDeck's own code. The facts it relies on were read from DSD-FME (frame sync,
triple-sent messages with the middle copy inverted, the BCH code parameters, ESK, the end-of-call dotting) and from
DSD and mbelib by the DSD and mbelib authors (ISC licence, https://github.com/szechyjs/dsd,
https://github.com/szechyjs/mbelib) for the ProVoice frame (sync patterns, bit layout and interleave schedule, the
code words of the 7100 x 4400 IMBE channel coding and their check rows, the scrambling sequence, and the reordering of
the voice parameters into P25 order). The BCH generator is computed from the code parameters, and the Golay and
Hamming decoders are TrunkDeck's own. The voice itself is decoded by JMBE, as for P25.

TrunkDeck's DMR and NXDN decoders are built on SDRTrunk's, by Dennis Sheirer (GPL-3.0-or-later,
https://github.com/DSheirer/sdrtrunk), included as source code in source/src/io/github/dsheirer: the DMR and NXDN
symbol processors, framers, message processors and message classes, and the DSP and error correction classes they
use. Each file keeps its copyright and licence header; files changed for TrunkDeck say so in their header, and
source/src/io/github/dsheirer/README-TRUNKDECK.txt gives the SDRTrunk version and summarises the changes. The adapters that
connect them to TrunkDeck (source/src/p25monitor/dmr/DmrDecoder.java, source/src/p25monitor/nxdn/NxdnDecoder.java)
and the small stand-in classes in io/github/dsheirer/compat are TrunkDeck's own.

Third-party software
--------------------
The full list, with licence texts, is in licenses/THIRD-PARTY.txt. In short:

* Bundled, unmodified, as separate libraries:
  - FlatLaf (Apache-2.0).
  - librtlsdr, RTL-SDR Blog v1.3.6 (GPL-2.0-or-later): app/native. Source in source/third-party.
  - libusb 1.0.27 (LGPL-2.1-or-later): app/native/windows-x64/libusb-1.0.dll, a separate DLL loaded at run time that
    you may replace with your own build. On Linux the system libusb is used. Source in source/third-party.
  - java-lame (LGPL-3.0): source in source/third-party.
  - JTransforms and JLargeArrays (BSD-2-Clause), Apache Commons Math (Apache-2.0), SLF4J API (MIT).
* Not included; built on your computer only if you ask for voice:
  - JMBE (GPL-3.0, https://github.com/DSheirer/jmbe). TrunkDeck downloads its source code and compiles it on your
    computer, or uses a JMBE jar you choose. The IMBE and AMBE+2 vocoders it implements are subject to patents held by
    Digital Voice Systems, Inc.
* Downloaded by the installer: Eclipse Temurin JDK (GPL-2.0 with the Classpath Exception).
* Reference only, no code included:
  - libairspy / airspyone_host (BSD-3-Clause): the USB protocol reference for TrunkDeck's own Airspy driver. Its
    gain-preset tables are used, with its copyright notice in licenses/airspyone_host-BSD-3-Clause.txt.
