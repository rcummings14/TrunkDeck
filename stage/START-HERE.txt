TRUNKDECK 1.7.0 - P25 Phase 1 and Phase 2 trunking monitor
==========================================================

WINDOWS:  open the "windows" folder and double-click Install.bat
LINUX:    open a terminal in the "linux" folder and run:  ./install.sh

Then start TrunkDeck from the Start Menu / app menu or the Desktop icon.
Full step-by-step guide (drivers, first start, CSV import, streaming): README.md

NEW IN 1.7.0: SDRPLAY, HACKRF ONE, LIMESDR AND ETTUS USRP - UNTESTED. These receivers now work through SoapySDR
(free drivers you install yourself; nothing new is bundled, and the SDRplay API must come from sdrplay.com). This support
has NOT been tested with real hardware - if something doesn't work, please report it on GitHub Issues
(https://github.com/rcummings14/TrunkDeck/issues) with "Copy diagnostics" from the Engine page. Airspy R2 and RTL-SDR
are tested and unchanged. What to install for Windows, Fedora and Debian/Ubuntu: README.md, "Supported receivers".

NEW IN 1.6.0: SET UP FROM RADIOREFERENCE. Systems -> Set up from RadioReference: sign in with your own RadioReference
Premium account, pick state -> county -> system (or a ZIP code / system ID), the site(s) and the talkgroups (all
non-encrypted ones are ticked, encrypted ones are marked and unticked), and TrunkDeck creates the system with its
control channels and talkgroup names. "Refresh from RadioReference" later merges new and renamed talkgroups and keeps
your mutes, favourites, recording and stream settings; nothing is deleted and feeds are never restarted. "Remember me"
is off by default. Needs a RadioReference app key (see README.md, "Set up from RadioReference"); builds without one
say so and everything else works as before.

NEW IN 1.5.1: NOW-PLAYING TAGS ON FEEDS. Broadcastify Feed and Icecast streams send the talkgroup of each call as the
stream title when the call starts playing on the feed (in queue order, so it matches the audio), like SDRTrunk does.
Streams -> your feed -> Now playing: on/off, Tag format (Talkgroup name / + radio name / ID + name / Custom with
{tg} {tgname} {radio} {radioname} {group} {tag}), Between calls (e.g. "Scanning...", empty = keep the last tag) and
Send test tag. It is a separate short request: the audio connection is never touched, and a failing tag only means
no title. At most one update every 1.5 s. Changes apply on Save stream without reconnecting.

NEW IN 1.5.0: DISPLAY ONLY. The "Display only" button in the header (or Ctrl+D) shrinks the window to just the big
scanner display - all its colours, the backlight on calls and the SCANNING ticker included. Resize it and the display
grows with it; drag it by the display. Double-click it (or Esc, Ctrl+D) for the full window again; right-click it for
Full window, Always on top, Mute speaker, Minimize to tray and Quit. Its size, place and Always on top are remembered.
Monitoring, the speaker, recordings, feeds and uploads keep running the whole time (nothing restarts).
Monitor page -> Listening: "Close (X)" and "Minimize" can each be Normal, System tray or Display only (defaults as
before: X -> System tray, Minimize -> Taskbar). The tray icon's menu has "Display only" too. Without a system tray
"System tray" is greyed out, Display only still works.
NEW DISPLAY COLOUR: Colors... -> Frame -> "Display border" colours the frame around the display (or None); Standard
(the default) is the frame as before.

The full manual is README.md (next to this file). Older release notes: the GitHub release history.
