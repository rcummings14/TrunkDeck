TrunkDeck 1.5.0 - third-party components
=========================================

Bundled in this zip
-------------------
FlatLaf 3.5.4 - Apache License 2.0 - https://github.com/JFormDesigner/FlatLaf
  app/flatlaf-3.5.4.jar (look and feel of the window). Licence: FlatLaf-LICENSE.txt
librtlsdr (RTL-SDR Blog rtl-sdr v1.3.6) - GNU GPL v2 or later - https://github.com/rtlsdrblog/rtl-sdr-blog
  app/native/windows-x64/rtlsdr.dll (official v1.3.6 Windows release build, libusb statically linked)
  and app/native/linux-x64/librtlsdr.so (built from the v1.3.6 source with gcc, dynamically linked to the system libusb-1.0).
  Complete source: source/third-party/rtl-sdr-blog-1.3.6.tar.gz. Licence: librtlsdr-GPL-2.0.txt
libusb 1.0.27 - GNU LGPL v2.1 or later - https://github.com/libusb/libusb
  app/native/windows-x64/libusb-1.0.dll (official libusb 1.0.27 release, MinGW64 build, unmodified; used by the Airspy
  R2 driver). It is a separate DLL loaded at run time - you may replace it with your own build of libusb.
  On Linux the system libusb-1.0 is used (Fedora: libusb1). Complete source: source/third-party/libusb-1.0.27.tar.bz2.
  Licence: libusb-LGPL-2.1.txt
java-lame 3.98.4 (Java port of the LAME MP3 encoder) - GNU LGPL v3 - https://github.com/nwaldispuehl/java-lame
  app/lib/java-lame-v3.98.4.jar, unmodified, kept as a separate jar (you may replace it with your own build).
  Used for MP3 recordings and streaming. Source: source/third-party/java-lame-3.98.4-src.tar.gz.
  Licence: java-lame-LGPL-3.0.txt (the LGPL adds to the GPL v3, GPL-3.0.txt)
JTransforms 3.1 - BSD 2-Clause - Copyright (c) 2007 onward, Piotr Wendykier - https://github.com/wendykierp/JTransforms
  app/lib/JTransforms-3.1.jar (needed by the JMBE voice codec). Licence: JTransforms-BSD-2-Clause.txt
JLargeArrays 1.6 - BSD 2-Clause - Copyright (C) 2013 onward University of Warsaw, ICM - https://gitlab.com/ICM-VisLab/JLargeArrays
  app/lib/JLargeArrays-1.6.jar (needed by JTransforms). Licence: JLargeArrays-BSD-2-Clause.txt
Apache Commons Math 3.6.1 - Apache License 2.0 - https://commons.apache.org/proper/commons-math/
  app/lib/commons-math3-3.6.1.jar (needed by JTransforms). Licence: commons-math3-Apache-2.0.txt, commons-math3-NOTICE.txt
SLF4J API 2.0.7 - MIT - Copyright (c) 2004-2023 QOS.ch - https://www.slf4j.org
  app/lib/slf4j-api-2.0.7.jar (logging interface used by the JMBE voice codec). Licence: slf4j-MIT.txt
The jars in app/lib are the unmodified releases from Maven Central / the project's GitHub release.

Downloaded by the installer (not in this zip)
---------------------------------------------
Eclipse Temurin JDK 25 (OpenJDK) - GNU GPL v2 with the Classpath Exception - https://adoptium.net
  The installer downloads the official build from github.com/adoptium and verifies its SHA-256 checksum, then puts it
  in the install folder's "runtime" folder. Its licence files are in runtime/legal. A full JDK (not just a runtime) is
  used because TrunkDeck compiles the JMBE voice codec from source on your computer.

Created on your computer (never in this zip)
--------------------------------------------
JMBE - GNU GPL v3 - https://github.com/DSheirer/jmbe
  TrunkDeck downloads the JMBE source code from GitHub and compiles it locally the first time voice is needed
  (or use "Choose jar..." to point at a JMBE jar you already have). Licence: GPL-3.0.txt
  The IMBE (Phase 1) and AMBE+2 (Phase 2) vocoders it implements are subject to patents held by Digital Voice
  Systems, Inc. TrunkDeck contains no vocoder code.

Reference only (no code or binary included)
-------------------------------------------
airspyone_host / libairspy - BSD 3-Clause - https://github.com/airspy/airspyone_host
  TrunkDeck's own Airspy R2 driver (Java, MIT) talks to the receiver over libusb. The USB protocol (vendor request
  numbers, sample formats) was read from libairspy's airspy.c; the linearity / sensitivity gain preset tables are
  taken from airspy.c with its copyright notice: airspyone_host-BSD-3-Clause.txt. libairspy's IQ converter and filter
  code (marked "for the Airspy ecosystem only") was not used - TrunkDeck has its own converter and filter bank.

TrunkDeck itself
----------------
TrunkDeck and its P25 engine - MIT (TrunkDeck-LICENSE.txt). Written from the published TIA-102 standards. The
  error-correction and coding tables are built from the standards' definitions (source/src/p25monitor/p25/CodeTables.java,
  with the standard section for each), and a test proves they are identical to the tables of earlier releases. See NOTICE.txt.
